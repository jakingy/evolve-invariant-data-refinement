# Isabelle theory contributions

This repository contains my Isabelle theory contributions
from my honours thesis about concurrent data refinement using an evolution invariant.
This theory extends an existing concurrent refinement algebra Isabelle theory base.
Complete new theories are in `theories/`. For theories that already existed,
`excerpts/` contains only the lemmas that were modified from the existing theory.
This Isabelle is not buildable on its own as it also requires the missing
concurrent refinement algebra theories.

The `DEAD/` theories are archived and no longer used.

A static website to browse the theories with proper Isabelle symbols and syntax highlighting can be found [here](https://jakingy.github.io/evolve-invariant-data-refinement/).

The website was generated by ChatGPT6.1 Sol.
Isabelle excerpts I modified were found using git blame and compiled together by ChatGPT6.1 Sol.
